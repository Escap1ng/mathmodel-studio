# 论文写作规范（精简版）

## 结构

- 题目、摘要、关键词必须在同一页；关键词后用 `\newpage`。
- 一级章节顺序：问题背景与重述 → 问题分析 → 模型假设 → 符号说明 → 数据处理（各问共用一套数据时设）→ 模型建立与求解 → 模型的评价、改进与推广。
- 每个问题的求解用二级标题「问题X模型的建立与求解」。
- 参考文献另起一页，附录另起一页。
- 导言区沿用给定骨架，不增删宏包；正文不出现作者身份与页眉。

## 标题

推荐组合：方法名 + 研究对象 + 问题类型，20–30 字。
示例：基于遗传算法的无人机投放策略优化研究；面向多源数据的产量预测与异常识别。

## 摘要（800–1000 字，五段式）

| 段 | 功能 | 写法 |
| --- | --- | --- |
| ① 钩子 | 具体矛盾、关键数字或决策困境 | 最多两句，直接切入 |
| ② 方法链 | 方法组合与一句话创新点 | 创新点回答“解决了旧方法解决不了的什么问题” |
| ③ 逐问结果 | 每问模型 + 算法 + 关键数值 + 对比 | 数值与正文表格同一小数位，问间递进显式写出 |
| ④ 稳健性 | 敏感性/交叉验证核心结论 | 一句话说明扰动下结论是否稳定 |
| ⑤ 映射 | 结果的现实意义与适用场景 | 落到具体场景，不写空泛意义 |

摘要必须含具体数值与误差分析；方法名称与正文一致；关键词 3–5 个，分号分隔。

## 模型假设与符号

- 假设用三线表：编号 | 假设内容 | 合理性说明，4–6 条，表题在上方。
- 符号用三线表：符号 | 含义 | 单位；正文首次出现时再次说明。

## 图表与数值

- 每张图、每张表都要有编号与标题，并在正文引用（如表X所示、由图X可见）。
- 数值只能来自本次 `result.json`，禁止编造没有运行过的结果；保留 2–4 位小数，全文一致。
- 求解图固定引用 `figures/final/fig1_residual.png`。
- 表格用三线表，不使用竖线。

## 表述

- 避免模板腔：不用“随着…的快速发展”“本文对…进行了深入研究”“得到了较为理想的结果”“具有一定的实际意义”。
- 改为具体写法：矛盾/数字直入；目标直述；给数值与对比；写明决策场景。
- 至少 2–3 处客观自审：假设 → 失效情形 → 量化影响 → 适用边界。
- 结论必须有数据或理论支撑；不确定结果明确标注范围。
- 算法介绍结合本题数据结构，写清选择理由与关键参数依据，不堆砌模型。

## 参考文献

- GB/T 7714 格式，5–8 篇，至少 2 篇近五年、1 篇英文，真实可查。
- 正文引用与文末条目一一对应。
